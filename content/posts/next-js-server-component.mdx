## 서버 컴포넌트

서버 컴포넌트는 Next.js 13+ App Router에서 기본값입니다. 서버에서 렌더링되며 클라이언트 측 JavaScript를 필요로 하지 않습니다.
데이터 fetching, 백엔드 리소스 접근, 민감한 정보 유지 등에 사용됩니다. async/await로 직접 데이터를 가져올 수 있어 편리합니다.

## 클라이언트 컴포넌트

파일 최상단에 `use client` 지시어를 추가하면 클라이언트 컴포넌트가 됩니다. useState/useEffect 같은 훅이나 이벤트 리스너, 브라우저 API를 사용할 때 필요합니다.

```jsx
'use client';

import { useState } from 'react';

export default function Counter() {
  const [count, setCount] = useState(0);
  // ...
}
```

## 서버 컴포넌트와 클라이언트 컴포넌트의 조합

서버 컴포넌트와 클라이언트 컴포넌트는 서로 중첩될 수 있습니다. 클라이언트 컴포넌트 내부에 서버 컴포넌트를 직접 import하는 것은 불가능하지만, `children` prop을 통해 중첩시킬 수 있습니다. 이를 `Composition pattern`이라고 합니다.

```jsx
// ClientWrapper.js (클라이언트 컴포넌트)
'use client'

export default function ClientWrapper({ children }) {
    return <div>{children}</div>
}

// Page.js
import ClientWrapper from './ClientWrapper'
import ServerComponent from './ServerComponent'

export default function Page() {
    return (
        <ClientWrapper>
            <ServerComponent />
        </ClientWrapper>
    )
}
```

이 구조에서 ServerComponent는 서버 측 렌더링 특성을 유지하면서 클라이언트 컴포넌트 내부에 중첩될 수 있습니다.
